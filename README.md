# P1-PUBLIC.1C.1 — Studio Website Foundation

This is the first local/static foundation for `polderlinegames.com`.

## Scope
- one page
- no JavaScript
- no analytics
- no contact form
- no cookies set by the site
- responsive layout
- approved Polderline Games / Paths of Kin branding
- links to the existing public studio accounts

## Recommended hosting
GitHub Pages through the `polderlinegames` organization.

Suggested repository:
`polderlinegames.github.io`

Keep GitHub Pages disabled while reviewing the site. When the page is approved, enable Pages and then connect `polderlinegames.com`.

## Files
- `index.html` — website
- `styles.css` — layout/branding
- `404.html` — simple fallback page
- `assets/` — locked brand assets
- `CNAME` — prepared custom-domain value for later use

## Important
Do not change TransIP DNS yet. The domain connection should be performed only after the site itself is approved.
